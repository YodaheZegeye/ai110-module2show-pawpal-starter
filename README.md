# PawPal+ (Module 2 Project)

You are building **PawPal+**, a Streamlit app that helps a pet owner plan care tasks for their pet.

## Scenario

A busy pet owner needs help staying consistent with pet care. They want an assistant that can:

- Track pet care tasks (walks, feeding, meds, enrichment, grooming, etc.)
- Consider constraints (time available, priority, owner preferences)
- Produce a daily plan and explain why it chose that plan

Your job is to design the system first (UML), then implement the logic in Python, then connect it to the Streamlit UI.

## What you will build

Your final app should:

- Let a user enter basic owner + pet info
- Let a user add/edit tasks (duration + priority at minimum)
- Generate a daily schedule/plan based on constraints and priorities
- Display the plan clearly (and ideally explain the reasoning)
- Include tests for the most important scheduling behaviors

## 🏗️ Implementation Summary

PawPal+ is architected around a clean separation of concerns between entity data models and scheduling logic:

- **`Task`**: Models atomic care activities (e.g., walking, medication, grooming) with duration, priority levels (`high`, `medium`, `low`), mandatory flags, frequency (`daily`, `weekly`), and completion status.
- **`Pet`**: Holds pet profiles (species, energy level, preferences) and manages pet-specific tasks via `add_task()`.
- **`Owner`**: Represents the pet parent, manages the daily time budget (`available_time_minutes`), and provides unified multi-pet access via `get_all_tasks()`.
- **`Schedule`**: Encapsulates the generated outcome, recording confirmed time slots, omitted tasks, budget tracking (`remaining_time_minutes`), and user-facing reasoning for every decision.
- **`Scheduler`**: The "brain" of the system. It retrieves tasks directly from `Owner.get_all_tasks()` for multi-pet scheduling, sorts tasks by urgency, assigns progressive chronological time slots starting at `08:00`, and ensures no tasks exceed the owner's available time.

## 📐 Smarter Scheduling

| Feature | Method(s) | Notes |
|---------|-----------|-------|
| Task sorting | `Scheduler._sort_tasks` | Sorts by mandatory flag (+100 score), priority (`high` > `medium` > `low`), and shortest duration first. |
| Filtering | `Scheduler._evaluate_fit` | Skips tasks exceeding remaining time budget and logs exact minute deficit. |
| Conflict handling | `Scheduler.generate_plan`, `_advance_time` | Assigns non-overlapping sequential time slots (e.g., `08:00`, `08:10`, `08:45`). |
| Recurring tasks | `Task.frequency` | Supports `daily`, `weekly`, and `as-needed` task cadences. |
